# The World in One Day — Thursday, 19 November 2026

A single image summing up the world's news of Thursday 19 November 2026,
built for the [make.fun news-image-20261119 bounty](https://make.fun/bounty/news-image-20261119).

The front page leads with the International Court of Justice ruling that
Myanmar committed genocide against the Rohingya, then the first-ever
Trump–Xi–Putin trilateral summit in Shenzhen, the worldwide launch of
Grand Theft Auto VI, Anthropic's blockbuster stock-market debut, and the
COP31 deadlock in Antalya — with Bangladesh, Greenland, Gaza and the US
Senate in the bottom strip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to the
output directory. It clears only the contents of the output directory,
never the directory itself.
